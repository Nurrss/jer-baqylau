# База знаний бота

Три процедуры × два языка: `ru/*.yaml`, `kk/*.yaml` (одинаковые `id` и порядок `order`).

⚠️ **Требует сверки с актуальным регламентом.** Тексты составлены по общедоступным описаниям
госуслуг на egov.kz и положениям Земельного кодекса РК. Номера статей закона намеренно не указаны.
Сроки и госпошлина помечены как ориентировочные — перед публикацией сверить с карточкой услуги.
Казахские тексты требуют вычитки носителем языка.

Поля: `id`, `order`, `emoji`, `title`, `summary`, `steps[]`, `documents[]`, `terms`, `fee`, `where`,
`links[] {title, url}`, `note`.
